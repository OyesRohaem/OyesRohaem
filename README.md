# 🏫 نظام إدارة المدرسة الابتدائية

نظام شامل لإدارة المدارس الابتدائية مطور بلغة Python باستخدام إطار العمل Flask.

## 🎯 الهدف

تطوير نظام إدارة مدرسة ابتدائية شامل يوفر جميع الأدوات اللازمة لإدارة العملية التعليمية بكفاءة عالية.

## 🚀 المميزات المخطط تطويرها

- ✅ إدارة المستخدمين والصلاحيات
- ✅ إدارة الطلاب والمعلمين
- ✅ نظام الحضور والغياب
- ✅ إدارة الجداول الدراسية
- ✅ نظام الامتحانات والتقييم
- ✅ إدارة الواجبات والأنشطة
- ✅ التقارير والتحليلات
- ✅ التواصل الداخلي
- ✅ إدارة الرسوم والفواتير
- ✅ المكتبة الإلكترونية

## 🛠️ التقنيات المستخدمة

- **Backend**: Python Flask
- **Database**: SQLAlchemy
- **Frontend**: Bootstrap (متجاوب)
- **Authentication**: Flask-Login
- **Reports**: Excel/PDF Export
- **QR Codes**: للحضور الإلكتروني

## 📱 المميزات الإضافية

- واجهة متجاوبة تعمل على جميع الأجهزة
- دعم اللغة العربية
- تصدير التقارير بصيغ مختلفة
- نظام QR Code للحضور
- رفع الصور والملفات

## 🔧 التثبيت والتشغيل

```bash
# تثبيت المتطلبات
pip install -r requirements.txt

# تشغيل التطبيق
python app.py
```
